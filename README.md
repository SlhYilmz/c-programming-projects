# C Programming Projects

A collection of small C projects covering fundamental algorithms, data
structures, serialization, and memory management.

## Projects

- [`sorting`](sorting/) — bubble sort, quicksort, and selection sort examples.
- [`data-structures`](data-structures/) — array, linked-list, queue, and stack
  operations.
- [`data-serialization`](data-serialization/) — serialization and
  deserialization exercises.
- [`memory-management`](memory-management/) — a linked-list-based memory
  allocation simulation.

Each project retains the commit history from its original repository. Build
instructions and project-specific documentation are available in the
corresponding directory.
