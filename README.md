# C Programming Projects

A collection of small C projects covering fundamental algorithms, data
structures, serialization, and memory management.

## Projects

- [`algorithms/sorting`](algorithms/sorting/) — bubble sort, quicksort, and selection sort examples,
  imported from [Sorting-Algorithms](https://github.com/SlhYilmz/Sorting-Algorithms).
- [`data-structures`](data-structures/) — array, linked-list, queue, and stack
  operations, imported from
  [operations-on-data-structures](https://github.com/SlhYilmz/operations-on-data-structures).
- [`data-serialization`](data-serialization/) — serialization and
  deserialization exercises, imported from
  [data-serialization](https://github.com/SlhYilmz/data-serialization).
- [`memory-management`](memory-management/) — a linked-list-based memory
  allocation simulation, imported from
  [MemoryManagementProject](https://github.com/SlhYilmz/MemoryManagementProject).

Each project retains the commit history from its original repository. Build
instructions and project-specific documentation are available in the
corresponding directory.
